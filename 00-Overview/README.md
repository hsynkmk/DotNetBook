## Learning objectives

After this chapter you should be able to:
- Explain the difference between .NET Framework, .NET Core, and modern .NET.
- Identify which runtime your app needs (CoreCLR, Mono, AOT).
- Name the main library families and their use cases.
- Pick the right SDK version (LTS vs STS).
